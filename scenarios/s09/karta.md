# ArcheoDąbrowa – scenariusz s09

- **Aplikacja:** ArcheoDąbrowa
- **Pomysł:** Stanowiska archeologiczne Dąbrowy Górniczej: co znaleziono i z jakiej epoki.
- **Ulubione:** stanowiska, które para chce odwiedzić.
- **Dane:** „Dąbrowa Górnicza: zabytki archeologiczne”, plik `data/raw/s09_dabrowa-zabytki-archeologiczne.csv`, w tabeli **135** (E1.rows) rekordów.
- **Atrybucja:** Źródło: Dąbrowa Górnicza, otwartedane.metropoliagzm.pl, CC BY 4.0. Strona zbioru: https://otwartedane.metropoliagzm.pl/dataset/60616698d4c313601e766da27640196b633b7c33b5d16f3c1b568bf977dec292

## Jak pracujecie

1. Role zmieniają się co etap. **Pilot** wkleja prompt do Kilo Code i akceptuje zmiany. **Kontroler danych** patrzy w plik CSV i w tę kartę.
2. Prompty: `prompty/etap1.md` … `prompty/etap4.md`. Gdy wynik nie zgadza się z kartą: `prompty/detektyw.md`.
3. Po każdym etapie sprawdźcie sekcję GOTOWE GDY narzędziem i porównajcie z liczbą z karty.
4. Pułapki w Waszych danych: `pulapki.md`. Zadanie dodatkowe: `prompty/gwiazdka.md`.
