# ArcheoDąbrowa – scenariusz s09

- **Aplikacja:** ArcheoDąbrowa
- **Pomysł:** Stanowiska archeologiczne Dąbrowy Górniczej: co znaleziono i z jakiej epoki.
- **Ulubione:** stanowiska, które para chce odwiedzić.
- **Dane:** „Dąbrowa Górnicza: zabytki archeologiczne”, plik `data/raw/s09_dabrowa-zabytki-archeologiczne.csv`.
- **Atrybucja:** Źródło: Dąbrowa Górnicza, otwartedane.metropoliagzm.pl, CC BY 4.0. Strona zbioru: https://otwartedane.metropoliagzm.pl/dataset/60616698d4c313601e766da27640196b633b7c33b5d16f3c1b568bf977dec292

## Jak pracujecie

1. Budujecie całą aplikację w 4 krokach: dane w bazie → wyszukiwarka → strona → logowanie i ulubione.
2. Wszystkie prompty są w `prompty.md`. Idźcie od góry do dołu.
3. **Pilot** kopiuje prompt do Kilo Code i akceptuje zmiany. **Nawigator** czyta pauzy, prowadzi decyzje i patrzy, czy wszystko działa. Po każdym kroku zamieniacie się rolami.
4. W pauzach wybieracie, jak ma wyglądać Wasza aplikacja. Nie ma złych odpowiedzi.
5. Skończyliście? Na końcu `prompty.md` są pomysły, co dodać samodzielnie.
