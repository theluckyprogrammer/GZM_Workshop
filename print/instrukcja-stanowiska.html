Instrukcja stanowiska

Rozszerzenia VS Code i klucz Kilo Code – przygotowanie komputera przed warsztatem „AI + otwarte dane GZM”. Strona do wydruku dla każdego, kto przygotowuje stanowisko. Reszta przygotowania (SDK, klucz do modelu AI): rozdziały 1–2 w docs/PROWADZACY.md.

1. Rozszerzenia VS Code

  1. Otwórz VS Code (ikona na pulpicie albo w menu Start).
  2. Kliknij ikonę rozszerzeń na lewym pasku bocznym – cztery kafelki, zaznaczone czerwoną ramką na zrzucie obok.
  3. W polu wyszukiwania u góry wpisz nazwę rozszerzenia, a na jego kafelku kliknij Install (zielony przycisk, czerwona ramka na zrzucie).

Tak zainstaluj wszystkie cztery rozszerzenia. Po instalacji VS Code może poprosić o restart – zgódź się.

code --install-extension ms-dotnettools.csharp
code --install-extension ms-dotnettools.csdevkit
code --install-extension qwtel.sqlite-viewer
code --install-extension kilocode.kilo-code

2. Klucz API w Kilo Code

Klucz Kilo (osobny na parę, z limitem) wpisuje prowadzący – uczniowie go nie przepisują i nie widzą. Kilo zapisuje klucz w bezpiecznym magazynie VS Code (Secret Storage).

  1. Najpierw sklonuj repozytorium: git clone https://github.com/theluckyprogrammer/GZM_Workshop.git. Zanim otworzysz folder w VS Code – Kilo przy pierwszym otwarciu czyta konfigurację z pliku kilo.jsonc w repo.
  2. Otwórz folder GZM_Workshop w VS Code: File → Open Folder…
  3. Kliknij ikonę Kilo Code na lewym pasku bocznym i przejdź do ustawień – konfiguracja API wygląda tak:
  1. W polu API Provider wybierz dostawcę wskazanego przez prowadzącego – na warsztacie OpenRouter (model jest już ustawiony w kilo.jsonc).
  2. Wklej klucz od prowadzącego w pole API Key (nazwa pola zależy od dostawcy, np. „OpenRouter API Key”):
  1. Sprawdź, czy działa: napisz w czacie Kilo krótkie pytanie, np. „Cześć, działasz?” – odpowiedź oznacza, że klucz jest dobry.

3. Ostatnie sprawdzenie stanowiska

  • Plik appsettings.Local.json (klucz do modelu AI, z pendrive'a prowadzącego) leży w szkielet\src\GzmApp.
  • Dwuklik na tools\check.cmd – wszystkie punkty OK, także „Model AI (gpt-6-luna)”.
  • Opisy scenariuszy do losowania i checklista stanowisk: rozdział 2 w docs/PROWADZACY.md.
